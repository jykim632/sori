## 3. 피드백 페이지 개선

### 3.1 새로고침 버튼 추가

**파일**: `apps/web/src/routes/admin/feedbacks.tsx`

- 결과 수 왼쪽에 RefreshCw 아이콘 버튼 추가
- 로딩 중일 때 아이콘 회전 애니메이션
- `router.invalidate()` 호출로 데이터 갱신

```tsx
<button
  onClick={() => router.invalidate()}
  disabled={isRouterLoading}
  className="p-1.5 text-gray-400 hover:text-gray-600 hover:bg-gray-100 rounded-lg"
  title="새로고침"
>
  <RefreshCw className={`w-4 h-4 ${isRouterLoading ? "animate-spin" : ""}`} />
</button>
```

### 3.2 시간 표시 추가

날짜 컬럼에 시간(HH:MM)도 함께 표시되도록 변경.

```tsx
// Before
{
  new Date(feedback.createdAt).toLocaleDateString("ko-KR");
}

// After
<div className="text-sm text-gray-400">
  <div>{date.toLocaleDateString("ko-KR")}</div>
  <div className="text-xs">
    {date.toLocaleTimeString("ko-KR", { hour: "2-digit", minute: "2-digit" })}
  </div>
</div>;
```

## 4. Slack 알림 디버깅

### 문제

시뮬레이터에서 피드백 API 호출 시 Slack 알림이 오지 않음.

### 추가한 로그

**피드백 API** (`apps/web/src/routes/api/v1/feedback.ts`):

```typescript
console.log("[notification] projectId:", projectId, "setting:", {
  emailEnabled, slackEnabled, slackWebhookUrl: "[SET]" or null
});
```

**Slack sender** (`apps/web/src/lib/notification/slack/index.ts`):

```typescript
console.log("[slack] sending to webhook, project:", project.name);
// ... fetch ...
console.log("[slack] sent successfully");
```

### 가능한 원인

1. 프로젝트에 알림 설정이 없음 (`setting: null`)
2. Slack 알림이 비활성화됨 (`slackEnabled: false`)
3. Slack webhook URL이 설정 안 됨 (`slackWebhookUrl: null`)

### 수정 사항

- APP_URL 기본값을 `https://web.sori.life`에서 `https://app.sori.life`로 수정
